1、页面组件：
输入框：输入股票的代码；
时间组件：从年精确到分钟；
下拉框：选择买入/卖出操作设置；
股票价格：当价格达到此价格时，将会自动下单
按钮：点击添加，将会生成委托单；
2、委托单列表展示：
委托单ID；
委托单股票代码；
委托单的类型：买入/卖出；
委托单的股票数量
委托单生成时间；
委托单的状态；
3、进入页面先查询该账户下的所有委托单，查询出该委托单的ID、股票代码、委托单是买入/卖出，委托单股票数量，委托单生成时间，委托单的状态，实时渲染到页面，每隔一分钟去IBKR查询一次委托单，检查是否有更新；
4、委托单的状态只有两个，提交/未提交，一进入页面查询的都是已经提交的委托单；
5、在页面组件上输入股票代码、股票的监控时间、操作选择，点击添加任务的按钮，将会把上面填写的条件加入到委托单列表中，此时委托单的ID、生成时间为空，因为只有当条件都满足时才会提交委托单，委托单状态是未提交；
6、当下拉框选择买入，并且填写了时间组件和股票价格，只有当价格大于或等于限定价格价格并且在次时间组件的时间范围内，才会下委托单，下委托单后记录下委托单的时间，修改委托单的状态，状态由未提交改为提交；若不满足，每隔30s去查询一次，查看是否满足；
7、当下拉框选择卖出，并且填写了时间组件和股票价格，只有当价格小于或等于限定价格价格并且在次时间组件的时间范围内，才会下委托单，下委托单后记录下委托单的时间，修改委托单的状态，状态由未提交改为提交；若不满足，每隔30s去查询一次，查看是否满足；
8、股票价格的查询，主要依靠雅虎财经的接口；，委托单是去IB-Gate中查询；
9、查询委托单要通过IBKR进行查询；

目的：此监控系统意在，某只股票当股价在某个时间内达到某个价格，将会向IBKR的后台自动的下委托单；

代码要求：需具备高可读性，通过规范命名、合理注释与清晰结构呈现；强调可维护性，遵循设计原则，实现低耦合高内聚与代码复用；注重可靠性，做好错误处理与全面测试；追求性能优化，优化算法与资源管理。

使用：IB Gateway +python后端+html、css、js作为前端；
